### PROJECTS

#### Personal projects

**leakwatch** — *Python*
- Command line tool, git pre-commit hook and GitHub Action that finds API keys, passwords and other secrets in your code and your git history
- No dependencies outside the standard library, tested with pytest and built with GitHub Actions
- `Python` `pytest` `GitHub Actions`
- [Repository](https://github.com/HamsaALT/leakwatch)

**a11ycheck** — *Java*
- Finds common accessibility problems in web pages (missing alt text, unlabelled fields, low contrast) and links each one to the WCAG criterion it breaks
- Text, JSON and HTML reports, with exit codes that work in a build pipeline
- `Java` `jsoup` `JUnit`
- [Repository](https://github.com/HamsaALT/a11ycheck)

**SecureCheck** — *C# · .NET Framework, migrated to .NET 10*
- A one-minute security check for a Windows PC: updates, antivirus, firewall, disk encryption and more, explained in plain language
- Read-only, with the same tool kept in two versions to show the migration from .NET Framework 4.7.2 to .NET 10
- `C#` `.NET` `xUnit`
- [Repository](https://github.com/HamsaALT/securecheck)

**PromptProof** — *C# · .NET 10*
- Regression tests for LLM prompts: measures a prompt on a labelled dataset, compares versions and fails the build when a change makes things worse
- Example task: triaging bug reports by severity and component
- `C#` `.NET 10` `xUnit` `Claude API` `Azure DevOps Pipelines`
- [Repository](https://github.com/HamsaALT/promptproof)

**Vikarbro** — *Java · Spring Boot · Angular*
- Helps a care home manager find a substitute fast: checks qualifications, overlapping shifts, 11 hours of rest and weekly hours, and explains why someone can't take a shift
- Offers go to several people at once and the first to accept gets the shift, safe under concurrent requests
- `Java` `Spring Boot` `PostgreSQL` `Angular` `Keycloak` `Testcontainers` `Power BI`
- [Repository](https://github.com/HamsaALT/vikarbro)

**GreenHour** — *Java · Spring Boot · Angular*
- Finds the cheapest or cleanest time to run a dishwasher or charge an EV, using live Danish electricity prices and CO₂ data from Energinet
- Compares every plan with starting right away, so the saving is visible
- `Java` `Spring Boot` `PostgreSQL` `Angular` `Keycloak` `Power BI`
- [Repository](https://github.com/HamsaALT/greenhour)

**Barrierefri** — *C# · .NET 10 · React*
- Map where people report accessibility barriers (broken lifts, blocked pavements, missing ramps), others confirm them, and staff get a case queue sorted by how overdue each repair is
- Built to meet WCAG 2.2 AA and tested for it with axe-core, contrast checks and keyboard tests
- `C#` `ASP.NET Core` `PostgreSQL` `React` `TypeScript` `Keycloak` `Docker` `Azure DevOps Pipelines`
- [Repository](https://github.com/HamsaALT/barrierefri)
